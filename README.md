# Dive Oxygen Toxicity Explorer

An educational web tool that shows how CNS and pulmonary oxygen toxicity
(CNS%, OTU, ESOT and ROT) build up during a dive and recover afterwards.

Live at **[o2toxicity.org](https://o2toxicity.org)**.

> Educational tool only — not for real dive planning.

## Run locally

Plain HTML/CSS/JS, no build step. Serve the folder over HTTP and open it:

```
python -m http.server 8642
```

Then open <http://localhost:8642/>.
