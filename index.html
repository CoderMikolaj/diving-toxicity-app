Dive Oxygen Toxicity Explorer

See how CNS and pulmonary oxygen toxicity build up during a dive and recover afterward.

Educational tool only — not for real dive planning. Assumes a square dive profile (instant descent/ascent, constant depth).
Indexes to show

Both indexes are shown as a % of a recommended limit so they can be compared on one scale: CNS% is already a % of the NOAA single-exposure limit; OTU is shown as a % of a commonly-cited 300 OTU/day reference. The vertical dashed line marks surfacing. CNS% decays after surfacing (~90 min half-time); OTU is shown flat since it has no recovery function, only a daily limit.
